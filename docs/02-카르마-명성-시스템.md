## 1. 목적

원본은 '카르마'를 차별화 포인트 4개 중 하나로 내세웠지만(p.10) 본문에 설계가 없습니다. 그런데 **재료는 이미 흩어져 있었습니다.**

| 원본에 이미 있던 것 | 위치 |
|---------------------|------|
| 출신 배경이 초기 **명성**, 초반 난이도, **NPC 행동 패턴**에 영향 | p.14 |
| 서브퀘스트·탐험 보상으로 **명성** 지급 | p.17, p.18 |
| 생활 루프에 **범죄**(도둑질·살인·배신) 갈래 | p.19 |
| 연계 기술 공격력 계산에 **관계도**가 가산 | p.40 |
| **Charm** 스탯이 NPC 호감도에 영향 | p.40 |
| 재료 획득 수단으로 **훔치기** | p.92 |
| 세력 3개 + 이교도 + 길드, 세력별 상충하는 목적 | p.98–100 |
| 챕터5에서 크레오스의 요구에 따른 **엔딩 분기** | p.104 |

이 문서는 이 8개 조각을 하나의 시스템으로 묶습니다. 새 기능을 얹는 것이 아니라, **이미 약속해 둔 것들을 연결하는 것**이 목적입니다.

### 1.1 설계 원칙

1. **선악이 아니라 대가.** 카르마 값이 높다고 좋은 게임이 되지 않는다. 모든 선택은 무언가를 얻고 무언가를 잃는다.
2. **본 것만 안다.** 평판이 변하려면 누군가 목격해야 한다. 이 한 줄이 원본의 '도둑질·살인·배신'을 게임적으로 의미 있게 만든다.
3. **모든 축은 관측 가능하다.** 플레이어는 자신의 4개 축 수치와 최근 변동 사유를 언제든 확인할 수 있다.
4. **되돌릴 수 있으나 공짜는 아니다.** 악명은 시간과 비용으로 씻을 수 있지만, 특정 임계를 넘은 사건은 영구 기록으로 남는다.

## 2. 4축 모델

| 축 | 범위 | 성격 | 주 영향 |
|----|------|------|---------|
| **명성** Renown | 0 ~ 1000 | 공개 · 단일 | 상점가, 퀘스트 해금, NPC 초기 태도, 길드 등급 |
| **세력 평판** Standing | −100 ~ +100 (5개 세력) | 공개 · 세력별 | 지역 접근, 전용 퀘스트·상점, 해당 세력 적의 강도 |
| **카르마** Karma | −100 ~ +100 | 은닉 가능 · 단일 | 동료 영입·이탈, 특정 대사 분기, 엔딩 분기 축 |
| **관계도** Bond | 0 ~ 100 (동료별) | 개별 | **연계 기술 공격력** (원본 p.40), 동료 개인 퀘스트, 이탈 판정 |

### 2.1 왜 4축인가

단일 "선악 게이지"는 두 가지 이유로 이 게임에 맞지 않습니다.

- 원본의 3세력은 **선악으로 정렬되지 않습니다.** 귀족회는 부패했지만 질서를 유지하고, 신정국은 신앙이 순수하지만 폭력적이며, 상회는 실리적이지만 플레이어에게 실질적 도움을 가장 많이 줍니다(p.98–100). 한 축으로는 이 삼각 구도를 표현할 수 없습니다.
- 원본 p.40의 **관계도는 이미 전투 수치에 들어가 있습니다.** 평판과 분리된 개별 축으로 두어야 "세상 사람들에게는 악명 높지만 동료들은 그를 따른다" 같은 상태가 성립합니다.

### 2.2 세력 5개

| 세력 ID | 이름 | 원본 근거 | 성향 축 |
|---------|------|-----------|---------|
| `ARD` | 아르디아 연맹 귀족회 | p.98 | 질서 · 이권 |
| `ZEN` | 제노스 신정국 | p.99 | 신앙 · 규율 |
| `SER` | 세룰 해양상회 연합 | p.100 | 실리 · 거래 |
| `GLD` | 모험가 길드 / 백금 수호협회 | p.13, p.102 | 중립 · 실적 |
| `SIL` | 침묵하는 짐승단 (이교도) | p.103–104 | 변혁 · 파괴 |

`GLD`는 다른 네 세력과 **상충하지 않습니다**(중립 창구). 나머지 넷은 §3.3의 상충 행렬에 따라 서로 영향을 주고받습니다.

## 3. 규칙

### 3.1 목격(Witness) 판정 — 이 시스템의 핵심

평판·카르마 변동은 **목격 여부**로 갈립니다.

```
행동 발생
  ↓
목격자 후보 수집: 반경 2500UU 내 NPC (원본 p.116 '안전 거리' 기준 재사용)
  ↓
각 후보에 대해 개별 판정:

  P_witness = base_perception
            × 거리계수 D
            × 시야계수 V
            × 시간계수 T
            × (1 − 은신보정 S)

    base_perception : NPC 유형별 기본 인지력 (표 3.1a)
    D = clamp(1 − 거리/2500, 0.1, 1.0)
    V = 1.0(정면 90°) / 0.5(측면) / 0.15(배후) / 0.0(차폐물)
    T = 1.0(주간) / 0.6(야간) / 0.4(눈보라·안개 등 시야 제한 지역)
    S = 0.02 × DEX + 0.01 × LUK + 은신 스킬 보정   (상한 0.85)
  ↓
1명 이상 목격 → "공개 행동"      : 명성·세력 평판·카르마 전부 변동
0명 목격      → "은닉 행동"      : 카르마만 변동, 명성·평판 불변
```

> **왜 카르마는 목격과 무관한가** 카르마는 "세상이 아는 나"가 아니라 "내가 한 일"입니다. 목격자를 지워도 한 일이 사라지지는 않습니다. 이 구분이 있어야 "완전 범죄"가 가능하면서도 무의미해지지 않습니다.

#### 표 3.1a — NPC 유형별 기본 인지력

| NPC 유형 | `base_perception` | 비고 |
|----------|-------------------|------|
| 일반 주민 | 0.45 | |
| 상인 | 0.60 | 자기 물건에 대해서는 0.95 |
| 위병 · 기사 | 0.85 | |
| 세력 요인 | 0.95 | 알베르트, 셀레나 등 |
| 동료 (파티원) | 1.00 | 항상 목격. §3.4 참조 |
| 아이 · 노인 | 0.30 | 다만 목격 시 소문 전파 속도 ×1.5 |

### 3.2 행동별 변동표

`Δ명성 / Δ카르마 / Δ평판` 순. 평판은 영향받는 세력만 표기.

#### 긍정 행동

| 행동 | Δ명성 | Δ카르마 | Δ평판 | 원본 근거 |
|------|-------|---------|-------|-----------|
| 메인 퀘스트 챕터 클리어 | +60 | 0 | 분기별 | p.18 |
| 서브 퀘스트 클리어 | +8 ~ +25 | 0 ~ +3 | 의뢰 세력 +2~5 | p.18 |
| 미확인 던전·스테이지 최초 발견 | +15 | 0 | `GLD` +3 | p.17 |
| 던전 최초 클리어 | +30 | 0 | `GLD` +5 | p.17 |
| 주민 구조 (선택적 이벤트) | +5 | +4 | 지역 세력 +1 | 신규 |
| 포로·죄수 사면 | +3 | +6 | `ZEN` −3, `ARD` −2 | 신규 |
| 세력 의뢰 완수 | +10 | 0 | 해당 +6 / 상충 −3 | §3.3 |

#### 부정 행동 — 생활 루프의 '범죄' 갈래 (원본 p.19)

| 행동 | Δ명성 | Δ카르마 | Δ평판 | 은닉 시 |
|------|-------|---------|-------|---------|
| **도둑질** (일반 물품) | −10 | −3 | 지역 세력 −2 | 카르마만 −3 |
| **도둑질** (상인 물품) | −18 | −4 | `SER` −6 | 카르마만 −4 |
| **훔치기** (전투 중 재료 획득, p.92) | 0 | −1 | 0 | 전투 중이므로 항상 은닉 |
| **살인** (일반 NPC) | −60 | −20 | 지역 세력 −15 | 카르마만 −20 |
| **살인** (위병·기사) | −90 | −25 | 해당 세력 −30 | 카르마만 −25 |
| **살인** (세력 요인) | −150 | −35 | 해당 −60, 상충 +15 | 카르마만 −35 |
| **배신** (수락한 퀘스트를 의뢰주 적대 세력에 넘김) | −40 | −25 | 의뢰주 −40, 수혜자 +25 | 은닉 불가 (§3.4) |
| 계약 파기 (퀘스트 포기) | −5 | −2 | 의뢰 세력 −5 | — |
| 협박·갈취 | −12 | −8 | 지역 세력 −4 | 카르마만 −8 |

> **살인의 카르마 값이 큰 이유** −20은 전체 범위(−100~+100)의 10%입니다. 5명을 죽이면 카르마가 최하위권으로 떨어져 동료 이탈 판정(§4.3)에 걸립니다. "죽여도 별일 없는" 상태를 만들지 않기 위한 값입니다. 〔검증필요: 플레이 테스트에서 우발적 살인 빈도 확인〕

### 3.3 세력 상충 행렬

한 세력의 평판이 오르면 상충 세력은 자동으로 내려갑니다.

```
Δ평판(대상) = 원래값
Δ평판(타세력) = 원래값 × 상충계수
```

| | ARD | ZEN | SER | GLD | SIL |
|---|---|---|---|---|---|
| **ARD** | — | −0.3 | −0.4 | 0 | −0.8 |
| **ZEN** | −0.3 | — | −0.2 | 0 | −1.0 |
| **SER** | −0.4 | −0.2 | — | 0 | −0.2 |
| **GLD** | 0 | 0 | 0 | — | −0.5 |
| **SIL** | −0.8 | −1.0 | −0.2 | −0.5 | — |

읽는 법: `ARD` 평판이 +10 되면 `ZEN`은 −3, `SER`은 −4, `SIL`은 −8.

**설계 의도**
- `ZEN ↔ SIL`이 −1.0(완전 대칭)인 이유 — 신정국의 존재 이유가 이교도 척결이므로(p.99) 양립 불가.
- `SER ↔ SIL`이 −0.2로 약한 이유 — 상회는 "이교도 정보를 가장 먼저 매매"(p.100)하는 실리 집단. 도덕적 반대가 아니라 이해관계.
- `GLD`가 전부 0인 이유 — 중립 창구여야 플레이어가 어느 노선을 타든 메인 진행이 막히지 않음.

### 3.4 동료 목격 예외

파티원은 **항상 목격**합니다(`base_perception` 1.00). 즉 동료가 보는 앞에서 저지른 범죄는 명성·평판에는 영향이 없어도(외부에 알려지지 않았으므로) **관계도에는 반드시 영향을 줍니다.**

```
IF 은닉 행동 AND 파티원 존재:
    명성·평판  변동 없음
    카르마     변동 적용
    관계도     각 동료의 가치관 대비 판정 → §4.2
```

'배신'은 성격상 반드시 상대 세력에 알려지므로 은닉이 불가능합니다.

### 3.5 소문 전파

목격된 공개 행동은 즉시 전역에 반영되지 않습니다.

| 단계 | 시점 | 범위 |
|------|------|------|
| 즉시 | 행동 시점 | 목격자 본인 및 반경 2500UU NPC의 태도 |
| 지역 | +1 게임일 | 해당 도시·마을 전체 NPC |
| 대륙 | +7 게임일 | 전 지역. 명성·평판 수치에 정식 반영 |

**7일의 유예**가 게임플레이를 만듭니다. 도시를 떠나기 전에 목격자를 매수하거나(`뇌물` 상호작용), 위병에게 자수하거나(벌금 지불 → 명성 손실 50% 감면), 관련 퀘스트로 상쇄할 수 있습니다.

### 3.6 감쇠와 속죄

| 대상 | 규칙 |
|------|------|
| 명성 (양수 방향) | 감쇠 없음. 누적 |
| 악명 (명성 손실분) | 게임 내 30일마다 −2씩 회복 |
| 세력 평판 | 게임 내 30일마다 0 방향으로 1씩 회귀 |
| 카르마 | **감쇠 없음** |
| 속죄 퀘스트 (`ZEN` 제공) | 명성 +30, 카르마 +5. 1회차당 3회 한정 |
| 벌금 납부 | 해당 사건의 명성 손실 50% 취소. 비용 = 손실분 × 200 골드 |

**중대 사건**(세력 요인 살인, 배신)은 감쇠·속죄 대상에서 제외되며 영구 기록으로 남습니다. 해당 세력 지역에서 상시 적대 상태가 됩니다.

## 4. 관계도 (Bond)

### 4.1 정의와 효과

원본 p.40이 이미 약속한 것: **연계 기술 공격력 = 장비 + 클래스 보정 + 캐릭터 능력치 + 관계도.**

```
연계_보정 = 1.0 + (Bond / 100) × 0.35        # 0 ~ +35%
합동_성공률_보정 = (Bond / 100) × 0.20        # 0 ~ +20%p (원본 p.27 합동 공격)
```

| Bond | 단계 | 해금 |
|------|------|------|
| 0–19 | 데면데면 | — |
| 20–39 | 동행 | 동료 1차 개인 대화 |
| 40–59 | 신뢰 | **합동 공격 해금**, 개인 퀘스트 1 |
| 60–79 | 결속 | 전용 연계 기술 1종, 개인 퀘스트 2 |
| 80–100 | 맹약 | 상위 연계 기술, 개인 퀘스트 3(최종), 엔딩 개별 에필로그 |

### 4.2 동료 가치관 축

각 동료는 4개 축에 대한 반응 계수를 가집니다. 같은 행동이라도 동료마다 관계도 변동이 다릅니다.

```
ΔBond(동료 i, 행동 a) = Σ_axis ( 행동_a의_축값 × 동료_i의_반응계수_axis )
```

| 축 | 설명 |
|----|------|
| `MERCY` | 자비 ↔ 냉혹 |
| `ORDER` | 질서 ↔ 자유 |
| `TRUTH` | 진실 ↔ 실용 |
| `PROFIT` | 이익 ↔ 헌신 |

예시 〔시나리오팀 확정 필요〕:

| 동료 | MERCY | ORDER | TRUTH | PROFIT |
|------|-------|-------|-------|--------|
| 셀레나 프람 (`ZEN` 출신, p.101) | +0.6 | +0.8 | +0.9 | −0.5 |
| 리라 (공방단, p.103) | +0.2 | −0.3 | +1.0 | 0.0 |
| 〔TBD 동료 3〕 | | | | |

셀레나 앞에서 포로를 사면하면 `MERCY`(+) × 0.6 = 관계도 상승, 동시에 `ORDER`(−) × 0.8 = 하락 — 순 효과는 소폭 상승. 같은 행동을 리라 앞에서 하면 거의 무반응. **동료 선택 자체가 플레이 스타일 선언**이 됩니다.

### 4.3 이탈 판정

```
매 챕터 종료 시 판정:

IF Bond < 15 AND |카르마 − 동료_허용카르마| > 60:
    동료 이탈 (파티에서 영구 제외, 세력에 따라 적으로 재등장 가능)

IF Bond < 15:
    경고 이벤트 1회 (다음 챕터까지 유예)
```

이탈한 동료의 전용 연계 기술은 사용 불가가 되며, 이는 **전투력의 실질적 손실**입니다. 원본이 "동료를 모아 마왕을 무찌른다"(p.4)고 한 이상, 동료를 잃는 것에 시스템적 대가가 있어야 합니다.

## 5. 시스템 연동

### 5.1 상점 가격 (원본에 없던 명성의 실효)

```
가격_배율 = 1.0
          − (명성 / 1000) × 0.15                    # 최대 −15%
          − (해당세력_평판 / 100) × 0.10             # 최대 ±10%
          − (Charm / 100) × 0.05                     # 원본 p.40 Charm 스탯 실효화
          + 악명_페널티

악명_페널티 = 0.20  IF 해당 지역 세력 평판 < −40
              0.50  IF 중대 사건 기록 존재
              (판매 거부: 평판 < −70)

적용 범위: 0.75 ~ 1.70
```

이 식이 원본 p.40의 **Charm 스탯에 실제 용도를 부여**합니다. 기존에는 "NPC 호감도에 영향"이라고만 되어 있었습니다.

### 5.2 NPC 태도 5단계

| 적대 | < −60 | 조우 시 즉시 전투. 상점·퀘스트 차단 |

## 6. 동적 난이도 연동

원본 p.33은 "선택에 따른 NPC 행동 변화로 난이도 조절"을 약속했습니다. 그 구현부입니다.

```
카르마_보정 = 세력_적대도 기반 DAI 가산

세력_적대도 = max(0, −평판(해당 지역 지배 세력)) / 100

DAI_가산 = 세력_적대도 × 0.12                    # 최대 +0.12
```

[적응형 AI §6-1](01-적응형-전투-AI.md#6-1-dai-범위-고정)의 DAI 상한 1.20 안에서 동작합니다. 즉:

- 특정 세력을 적대하면 그 세력 영역의 전투가 **최대 12% 어려워집니다.**
- 대신 해당 지역의 **은닉 행동 성공률과 이교도 계열 보상이 올라갑니다.**
- 반대로 평판이 높은 지역에서는 위병 지원 난입(§5.2 헌신)으로 전투가 쉬워집니다.

이 방향성이 §1.1-1 원칙("벌하지 않고 다르게 만든다")과 일치합니다.

### 6.1 최종 보스 난이도 (원본 p.20)

> "메인 퀘스트 혹은 서브퀘스트, NPC와의 교류 등과 같은 플레이적 요소와 플레이어 캐릭터 성장 요소에 따라 동적으로 보스 몬스터의 난이도를 조절한다" — 원본 p.20

```
최종보스_난이도 = base
                × (1 + 성장_지수 × 0.15)
                × (1 − 지원_지수 × 0.20)

성장_지수 = clamp( (평균 파티 레벨 − 권장 레벨 55) / 15, −1, +1 )
지원_지수 = ( Σ 평판(ARD,ZEN,SER,GLD) / 400 ) 를 0~1로 정규화
            + (동료 중 Bond ≥ 60 인원 수 / 4) × 0.5
            를 0~1로 clamp
```

**의미** — 세력을 두루 우호로 만들고 동료와 깊게 결속한 플레이어는 최종전에서 세력 지원(난입 유닛, 사전 폭격, 보급)을 받아 최대 20% 쉬워집니다. 홀로 강해진 플레이어는 지원 없이 순수 스펙으로 싸웁니다. **두 경로 모두 유효하며, 이것이 "선택에 따른 난이도 조절"의 실제 모습입니다.**

## 7. 엔딩 분기

원본 p.104는 "크레오스가 선택을 요구 → 최종 선택에 따라 엔딩 분기"까지만 정의했습니다. 분기 조건을 확정합니다.

### 7.1 분기 축

```
X축: 카르마          (−100 ~ +100)
Y축: 최다 평판 세력   (ARD / ZEN / SER / GLD / SIL)
Z축: 챕터5 최종 선택  (3지선다 — 크레오스의 제안)
```

**크레오스의 3지선다** 〔시나리오팀 확정 필요, 가안〕
1. **봉인** — 마나 순환을 원래대로 되돌린다. 폭증 이전의 세계.
2. **개방** — 마나를 모두에게 개방한다. 질서는 무너지되 독점도 끝난다.
3. **계승** — 마나 제어권을 플레이어가 쥔다. 던전01의 "제3의 선택"(p.143) 복선 회수.

### 7.2 엔딩 매트릭스

| 엔딩 | 조건 | 결말 |
|------|------|------|
| **회귀** | 선택=봉인, 카르마 ≥ 0 | 마나 폭증 이전으로. 세력들은 원래 자리로 돌아가고 아무것도 해결되지 않지만 아무도 더 죽지 않는다 |
| **정화의 대가** | 선택=봉인, 카르마 < −30 | 봉인은 성공하나 대가로 마나 도시들이 소멸. 그곳 주민들은 계산에 없었다 |
| **범람** | 선택=개방, 최다 평판 = `SIL` | 침묵하는 짐승단의 승리. 질서 붕괴 후의 세계를 크레오스와 함께 목격 |
| **새로운 균형** | 선택=개방, 최다 평판 = `SER`, 카르마 ≥ 0 | 상회가 마나 유통을 중개하는 새 질서. 완벽하지 않지만 작동한다 |
| **성좌의 계승자** | 선택=계승, 던전02 '세레스' 관련 선택지 전량 회수 | 플레이어가 세레스의 자리를 잇는다. 인간을 오염원으로 보지 않는 관리자로서 |
| **참칭자** | 선택=계승, 카르마 < −60 | 계승은 성공하나 세레스와 같은 결론에 도달. 두 번째 아스트리움이 시작된다 |
| **홀로 남은 용사** | 최종전 시점 파티 동료 0명 | 어떤 선택을 하든 그 결과를 함께 볼 사람이 없다 |
| **진 엔딩: 또 하나의 이야기** | 선택=계승 + 카르마 ≥ +60 + 전 동료 Bond ≥ 60 + 던전01 '제3의 선택' 달성 | 타이틀 회수. 〔시나리오팀 작성〕 |

### 7.3 에필로그

엔딩 본편과 별개로 **동료별 에필로그**가 Bond ≥ 80 인 동료 수만큼 재생되고, **세력별 후일담**이 평판 ≥ +40 인 세력마다 재생됩니다. 이것이 DLC(확장팩) 후일담과 연결되는 지점입니다 → [사업성 §4.2](04-사업성-손익-계획.md#42-dlc-설계-방향)

## 9. UI 요구사항

→ 상세 [03 UI/UX §5](03-UI-UX-설계.md#5-평판-화면)

최소 요구:
1. **평판 화면** — 4축 현재값 + 최근 변동 10건(사유 포함)
2. **소문 대기열 표시** — 아직 전파되지 않은 목격 사건과 남은 일수. 대응 가능하다는 사실을 알려야 함
3. **행동 전 경고** — 목격자가 있는 상태에서 범죄 상호작용 시도 시 아이콘 표시 (👁 N명). 실수로 명성을 잃게 하지 않음
4. **동료 관계도** — 각 동료의 4축 반응 계수는 **직접 노출하지 않고**, 최근 반응("셀레나가 당신의 결정을 마음에 들어하지 않았다")으로 간접 전달
