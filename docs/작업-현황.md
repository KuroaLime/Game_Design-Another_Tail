```

  ├ 무기          = 8.0 L + 12
  ├ 직업 기본     = 2.0 L + 20
  └ 스탯 기여     = 4.6 L + 9
플레이어 HP(L)   = 55 L + 180
플레이어 MP(L)   = 9 L + 50
플레이어 DEF(L)  = 5.5 L + 25

### 7.2 몬스터 곡선 ([06 §3.1–3.2](06-밸런스-테이블.md#31-기준-곡선-일반-몬스터))

```

### 7.3 전투 공식 ([05](05-데미지-공식-검증.md))

      M 스킬 계수 / E 속성 보정 / W 상성 / C 크리티컬
      B 브레이크 / R 방어비율 / LC 레벨차 / V 난수

W  약점 ×1.50 · 보통 ×1.00 · 내성 ×0.60 (적응 내성 상한 0.40)

     클래스계수  도적 1.15 / 궁수 1.10 / 마법사 1.00 / 성직자 0.95 / 전사 0.90

### 7.6 재계산 스크립트

이 문서의 표들은 전부 `awk`로 계산했습니다. 새 세션에서도 같은 방식으로 검산하세요.

```bash
# 예: 방어 비율이 전 레벨 구간에서 일정한지 확인
awk 'BEGIN{k=1.6
  for(i=1;i<=4;i++){L=(i==1?20:(i==2?35:(i==3?45:55)))
    atk=14.6*L+41; mdef=6*L+20
    printf "Lv%-3d  R=%.3f\n", L, atk/(atk+mdef*k)}}'

# 예: k를 목표 방어비율에서 역산
awk 'BEGIN{r=14.6/6.0; for(t=0.45;t<=0.61;t+=0.05)
  printf "목표 R %.2f → k = %.2f\n", t, r*(1/t-1)}'
```

> Windows 환경에서 `python`은 Microsoft Store 스텁이라 동작하지 않습니다. **`awk`(Git Bash 동봉)를 쓰세요.** PDF 렌더링은 Ghostscript(`/c/Program Files/gs/gs10.06.0/bin/gswin64c.exe`)를 사용했습니다.

## 9. 원본 덱 수정 — 정오표 25건

[00 정오표](00-정오표.md)에 **대체 문안까지 전부 작성**되어 있습니다. PPT를 열고 그대로 옮기면 됩니다.

```
A. 데이터 오류 (치명)      E-01 ~ E-04     4건
B. 설계 불일치 (높음)      E-05 ~ E-12     8건

E. 밸런스 (2차 발견)       E-22 ~ E-25     4건
────────────────────────────────────────────

```

**작업 순서 권고** — 치명(A + E-22) → 템플릿 잔존(C) → 설계 불일치(B) → 나머지.
C를 두 번째로 두는 이유는 시각적으로 가장 먼저 눈에 띄고 수정 비용이 가장 낮기 때문입니다.

**진행 체크리스트는 [00 정오표 마지막 절](00-정오표.md#진행-체크리스트)에 있습니다.** 수정할 때마다 체크하고 `해결일`을 기록하세요.

## 11. 유지해야 할 원칙
