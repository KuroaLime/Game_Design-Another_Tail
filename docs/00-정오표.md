## 사용법

각 항목은 **위치 → 현재 상태 → 문제 → 수정안** 순으로 되어 있습니다. `수정안` 블록의 문구는 그대로 슬라이드에 붙여 넣을 수 있게 작성했습니다.

| 우선도 | 기준 |
|--------|------|
| **치명** | 심사자가 읽는 즉시 완성도를 의심하게 되는 것. 데이터 자체가 틀린 것 |
| **높음** | 설계 불일치. 구현 단계에서 반드시 문제가 되는 것 |
| **중간** | 미작성·템플릿 잔존. 성의 문제로 읽히는 것 |
| **낮음** | 표기·정렬 |

**작업 순서 권고** — 치명 → 중간(템플릿 잔존) → 높음 → 낮음.
중간을 두 번째로 두는 이유는, 템플릿 잔존이 시각적으로 가장 먼저 눈에 띄고 수정 비용이 가장 낮기 때문입니다.

## A. 데이터 오류 (치명)

### E-01 · 보스 레벨 표기 불일치
**우선도 치명** · 위치 p.197–198 / p.202, p.170 / p.174

| | 몬스터 카드 | 배치표 |
|---|---|---|
| 심연의 합창단 | **Lv 45** (p.197) | **Lv 55** (p.202) |
| 타락한 빛 : 세레스 | **Lv 45** (p.170) | **Lv 55** (p.174) |

**문제** 같은 개체의 레벨이 두 슬라이드에서 다릅니다. 던전03의 일반 몬스터가 Lv 45, 엘리트가 Lv 50이므로 보스가 Lv 45면 엘리트보다 약합니다. 배치표의 Lv 55가 맞습니다.

**수정안**
```
p.197  심연의 합창단  레벨 : 55
p.170  타락한 빛 : 세레스  레벨 : 55
```
아울러 **몬스터 카드의 레벨 표기를 전부 배치표 기준으로 재확인**하십시오. 카드 슬라이드가 템플릿 복사로 만들어졌기 때문에 다른 개체에도 같은 문제가 있을 가능성이 높습니다.

### E-02 · 던전02 몬스터 분류가 던전01 값
**우선도 치명** · 위치 p.169

**현재**
```
마나 거미 (Aether Spider)   분류 : 시간 벌레
코어 가디언 (Core Guardian) 분류 : 시간 벌레
에너지 리치 (Mana Lich)     분류 : 시간 벌레
```

**문제** '시간 벌레'는 던전01 리테르나(시간 테마)의 분류입니다. 던전02 아스트리움 타워는 마나·인공생명 테마이며, 해당 슬라이드의 공통 컨셉도 "성공한 실험체 / 기계 공학 · 생명 공학"으로 되어 있습니다. 분류만 복사된 상태입니다.

**수정안**
```
마나 거미 (Aether Spider)    분류 : 마나 기생체
코어 가디언 (Core Guardian)  분류 : 인공 골렘
에너지 리치 (Mana Lich)      분류 : 마나 정령
```

### E-03 · 던전03 맵 크기가 던전02 값
**우선도 치명** · 위치 p.184

**현재** `스테이지 크기 : 맵 100 x 100 x 600 m`

**문제** `600m` 높이는 수직 타워인 아스트리움 타워(p.157)의 값입니다. 심연의 성가는 수도 하층의 수평 사원 구조이며, 하위 4개 구역의 합산 크기와도 맞지 않습니다.

**수정안**
```
스테이지 크기
  1. 맵 크기        200 x 180 m
  2. 침묵의 회당    100 x 80 m
  3. 울림의 낭하    120 x 120 m
  4. 사념의 제단    150 x 90 m
  5. 심연의 성가대   70 x 70 m
```
아울러 하위 구역 번호를 **진행 순서대로** 정렬하십시오. 현재 p.184는 `3.심연의 성가대 → 4.사념의 제단` 순으로 되어 있으나 실제 동선은 회당 → 낭하 → 제단 → 성가대입니다.

### E-04 · 던전02 중간 보스가 던전01 보스
**우선도 치명** · 위치 p.173

**현재** `④ Lv 55  리테르나의 정예 기사 - 아르난` (아스트리움 타워 '마나의 핵' 구역)

**문제** 아르난은 던전01 리테르나의 중간 보스입니다(p.155). 던전02에 다시 등장할 서사적 근거가 없습니다.

**수정안**
```
④  Lv 55   오염된 복제체 "에코"
```
단, '에코'는 이미 p.172(심층 제어실)의 중간 보스로 배치되어 있습니다. 둘 중 하나를 선택하십시오.

- **안 A (권장)** — 심층 제어실 중간 보스를 `철혈의 관리자 바이스오더 Lv55`로 승격하고, 마나의 핵을 '에코'로 둔다. 서사상 '핵'에 가까울수록 세레스의 복제 실험 결과물이 나오는 것이 자연스럽습니다.
- **안 B** — 마나의 핵에는 중간 보스를 두지 않고 부 보스 조우만 유지(p.165의 동선 플로우가 이미 "④ 부 보스 출현"으로 되어 있음).

## B. 설계 불일치 (높음)

### E-05 · 직업 수 4종 vs 5종
**우선도 높음** · 위치 p.16 / p.41–42

**현재** 튜토리얼(p.16)은 `전사 / 마법사 / 궁수 / 도적` 4종, 스킬 챕터(p.41–42)는 `전사 / 마법사 / 궁수 / 도적 / 성직자` 5종.

**수정안** **5종으로 통일**합니다. 성직자는 p.42에 클레릭·오라클 계열의 상위 클래스가 이미 설계되어 있고, 파티 4인 구성에서 회복 역할이 필요합니다.

```
p.16 수정 문안

1. 전투 시스템 가이드 종료 후, 교관 NPC의 안내에 따라 다섯 직업
   (전사 · 마법사 · 궁수 · 도적 · 성직자) 중 하나를 선택한다.
2. 선택한 직업의 전직관으로 이동하여, 해당 직업이 다룰 수 있는
   여러 무기 중 1개를 고른다.
3. 플레이어 캐릭터의 성장 시스템(숙련도 · 스킬)에 대한 가이드를 받는다.
```

### E-06 · '아머드 리전' 중복
**우선도 높음** · 위치 p.42

**현재** `아머드 리전`이 전사 → 용병 계열과 도적 → 로그 계열 양쪽의 상위 클래스로 등장합니다.

**문제** 상위 클래스는 "특정 무기 특성화 + 스탯 보정 + 상위 기술"을 부여하는 고유 노드입니다(p.42). 서로 다른 기본 직업에서 같은 이름의 클래스로 수렴하면 두 계열의 정체성이 무너집니다.

**수정안** 도적 → 로그 계열의 것을 개명합니다. 로그의 방어형 분화라는 성격을 살립니다.
```
도적 → 로그 → 새도어 / 나이트레스 / 팬텀 가드
```

### E-07 · 실명과 수면의 효과가 동일
**우선도 높음** · 위치 p.45

**현재**
```
실명 (Blind)  명중률 및 치명타 확률 감소
수면 (Sleep)  명중률 및 치명타 확률 감소
```

**문제** 상태이상 16종 중 2종이 완전히 같은 효과입니다. 수면은 통상 행동 불가 계열입니다.

**수정안**
```
수면 (Sleep)  일정 턴 동안 행동 불가. 피격 시 즉시 해제되며,
              해제 시점의 피해량이 1.5배로 적용된다.
```
`피격 시 해제 + 피해 증폭`은 [속성 연쇄](README.md)와 맞물려 "재우고 → 큰 거 한 방"이라는 전술을 만듭니다. 단순 행동 불가보다 이 게임의 시스템에 더 잘 붙습니다.

### E-08 · 재료 아이템 분류표가 소비 아이템 표 내용
**우선도 높음** · 위치 p.90

**현재** 재료 아이템 4분류(채집 / 몬스터 부산물 / 희귀 특수 / 분해 재료)의 `예시 · 핵심 역할 · 쿨타임` 칸에 p.86 소비 아이템 표의 내용(HP 포션, 생존, 자신 턴 마다 …)이 그대로 들어가 있습니다.

**수정안** 표 헤더를 재료에 맞게 바꾸고 내용을 채웁니다. `쿨타임` 열은 재료 아이템에 무의미하므로 `주 사용처`로 교체합니다.

| 분류 | 예시 | 핵심 역할 | 주 사용처 |
|------|------|-----------|-----------|
| 채집 (Gathering) | 약초, 마나 이끼, 서리꽃, 철광석 | 제작 기본 자원 | 연금술 · 요리 |
| 몬스터 부산물 (Monster Trophies) | 잔향의 파편, 갑주 조각, 사념 결정 | 중급 제작 · 특성 부여 | 수선 · 연금술 |
| 희귀 특수 (Special Materials) | 시간의 모래, 역류한 마나 결정, 성가의 잔향 | 상위 장비 제작 · 강화 | 장비 강화 |
| 분해 재료 (Disassembly Parts) | 마력 실, 정제된 금속, 마석 가루 | 장비 분해 산출물 | 장비 제작 · 마법 내장 |

> 예시 아이템명은 각 던전의 테마(시간 / 마나 / 소리)에서 가져왔습니다. 던전 클리어와 제작 시스템이 연결되어 있음을 표로 보여주는 것이 목적입니다.

### E-13 · 도시02·03 스테이지 정보가 '시작의 마을' 템플릿
**우선도 중간** · 위치 p.129–137

**현재**
- 도시02 '고요한 절벽의 성채' · 도시03 '철과 기계의 도시'의 `플레이 역할`, `목적` 칸이 시작의 마을 문구 그대로 (`플레이어의 시작 지역`, `기본적인 게임의 분위기와 모험에 대한 당위성 제공`)
- 두 도시 모두 `스테이지 크기`가 `마을 70×70×πm / 회관 14×12m / 가정집 8×8m` 로 시작의 마을 값 그대로
- 도시03은 `시나리오 컨셉`·`배경 그래픽 컨셉` 칸까지 시작의 마을 문구

**수정안** — 도시02 고요한 절벽의 성채
```
플레이 역할  마나 폭증에서 소외된 지역의 실상 제시. 자원 분배 갈등 서브 라인 진입점
목적        번영한 마나 도시(마을01)와의 대비를 통해 세계관의 이면을 체감시키는 것

스테이지 크기
  1. 성채 면적      180 x 120 m (협곡 사이 종단형)
  2. 성채 본관       40 x 30 m
  3. 하부 마을       80 x 60 m
  4. 강변 부두       30 x 20 m
```

**수정안** — 도시03 철과 기계의 도시
```
시나리오 컨셉
  설산 고지대에 세워진 마력 기계 도시. 폭증한 마나를 기계 동력으로 전환하는
  기술로 급성장했으나, 원인 모를 한기가 도시를 잠식하며 광산 노동자들이
  차례로 사라지고 있다. 도시는 생산을 멈출 수 없다는 이유로 이를 은폐한다.

배경 그래픽 컨셉
```

### E-25 · 계산식 슬라이드의 변수 지정·명칭 오류
**우선도 높음** · 위치 p.95

**현재**
```
유효 방어력 = 공격 속성(물리/마법) × ( 1 + 방어 증가% − 방어 감소% ) + 실드/배리어 고정치
최종 방어력 = 스킬 공격력 × 방어 비율
```

**문제**
1. 첫 식은 좌변이 *방어력*인데 우변 첫 항이 `공격 속성`입니다. 방어력이어야 합니다.
2. 둘째 식은 좌변 명칭이 *방어력*인데 실제로는 **데미지**입니다.
3. `방어력 계수`가 `테스트를 통한 적절한 계수 조절 필요`로 미정이어서 식 전체가 계산 불가 상태입니다.

**수정안**
```
유효 방어력 DEF_eff = 방어력(물리 또는 마법)
                    × ( 1 + 방어 증가% − 방어 감소% )
                    × ( 1 − 방어 무시율 )
                    + 실드 / 배리어 고정치

방어 비율 R = 공격력 / ( 공격력 + DEF_eff × k )        k = 1.60

최종 데미지 = 공격력 × 스킬 계수 × 속성 보정 × 상성 배율
            × 크리티컬 × 브레이크 배율 × R × 레벨차 보정 × 난수
```
`방어 무시율`과 연산 순서는 원본에 없던 항입니다. p.47이 브레이크 효과로 "방어 무시 피해 증가"를 명시했으므로 반드시 필요합니다.
→ k = 1.60 도출 과정 [05 §4](05-데미지-공식-검증.md#4-방어력-계수-k-도출-f-3-해소) · 연산 순서 [05 §3.4](05-데미지-공식-검증.md#34-연산-순서-f-4-해소)
