## 1. 목적

원본은 챕터 5개의 흐름(p.102–104)과 스테이지별 퀘스트 **이름**(p.119–202)을 갖고 있었지만, 그 사이가 비어 있었습니다.

| 원본에 있던 것 | 없던 것 |
|---|---|
| 챕터별 배경 도시와 사건 요약 | 씬 단위 진행, 진입·종료 조건 |
| 퀘스트 이름 약 20개 | 내용, 선행 조건, 보상, 평판 영향 |
| "동료들을 모아"(p.4), 캐릭터 2명(p.101) | **동료 명단 자체** |
| "최종 선택에 따라 엔딩 분기"(p.104) | 분기 조건, 플래그, 엔딩 스크립트 |

이 문서는 그 사이를 채웁니다. 총 **메인 31단계 + 서브 56개 + 동료 개인 15개 + 던전 내 14개 = 116개** 퀘스트를 정의합니다.

## 2. 동료 캐릭터 확정

원본은 셀레나 프람과 리라 두 명만 언급했습니다. 파티는 4인이고([03 UI §3.7](03-UI-UX-설계.md#37--파티-상태)), 원본이 "동료들을 모아"를 핵심 컨셉으로 삼았으므로 **선택의 여지가 있으려면 5명**이 필요합니다.

### 2.1 편성 원칙

```
파티 4인 = 주인공(직업 자유 선택) + 동료 5명 중 3명
동료 5명 = 5개 직업 1:1 대응 + 5개 세력 1:1 대응
```

**세력과 동료를 1:1로 묶은 것이 이 설계의 핵심입니다.** 동료를 고르는 것이 곧 세계관의 어느 시선을 옆에 둘지 고르는 것이 되고, [02 카르마](02-카르마-명성-시스템.md)의 평판 축이 파티 편성에서 직접 체감됩니다.

### 2.2 동료 5인

| 코드 | 이름 | 직업 | 세력 | 합류 | 한 줄 |
|---|---|---|---|---|---|
| `KAI` | **카일 베르그** | 전사 | `ARD` 아르디아 | 챕터1 | 알베르트 가문 방계의 몰락 기사. 자기가 지키려는 질서가 이미 썩었다는 것을 알면서도 놓지 못한다 |
| `MIR` | **미르 하벤** | 도적 | `SER` 세룰 | 챕터1 | 상회 소속 정보상. 모든 것에 값을 매기지만, 값을 매길 수 없는 것이 있다는 걸 인정하지 않는다 |
| `SEL` | **셀레나 프람** | 성직자 | `ZEN` 제노스 | 챕터2 | 순수파 사제 기사. 신념이 강한 만큼, 신념이 틀렸을 때 부러진다 (원본 p.101) |
| `LIR` | **리라 아셴** | 마법사 | 공방단 (중립) | 챕터3 | 마나 변성 연구자. 진실만이 유일한 가치이고 그 대가는 계산에 넣지 않는다 (원본 p.103) |
| `NAI` | **네이르** | 궁수 | `SIL` 침묵하는 짐승단 이탈자 | 챕터4 (조건부) | 변성 숲 출신. 짐승단이 옳다고 믿었고, 지금도 완전히는 부정하지 못한다 |

### 2.3 4축 반응 계수 ([02 §4.2](02-카르마-명성-시스템.md#42-동료-가치관-축) 해소)

| 동료 | `MERCY` | `ORDER` | `TRUTH` | `PROFIT` | 허용 카르마 |
|---|---:|---:|---:|---:|---:|
| 카일 (KAI) | +0.5 | **+0.9** | +0.3 | −0.6 | +30 |
| 미르 (MIR) | +0.1 | −0.7 | −0.2 | **+0.9** | −10 |
| 셀레나 (SEL) | +0.6 | +0.8 | **+0.9** | −0.5 | +45 |
| 리라 (LIR) | +0.2 | −0.3 | **+1.0** | 0.0 | 0 |
| 네이르 (NAI) | −0.4 | **−0.9** | +0.5 | +0.2 | −40 |

> 셀레나·리라 값은 [02 §4.2](02-카르마-명성-시스템.md#42-동료-가치관-축)에 이미 기재된 것을 그대로 계승했습니다.
> `허용 카르마`는 [02 §4.3](02-카르마-명성-시스템.md#43-이탈-판정) 이탈 판정에 사용합니다 (`|카르마 − 허용| > 60` 이고 Bond < 15 이면 이탈).

**대칭 설계** — 카일(ORDER +0.9)과 네이르(ORDER −0.9)가 정반대입니다. 두 명을 동시에 파티에 넣으면 거의 모든 선택에서 한쪽의 관계도가 떨어집니다. **"둘 다 데리고 갈 수는 없다"** 가 시스템으로 성립하며, 이것이 2회차의 동기가 됩니다.

| 동료 | 조건 |
|---|---|
| KAI | 챕터1 `MQ-1-3` 클리어 시 자동 |
| MIR | 챕터1 `SQ-SAV-04 밝혀진 배후` 클리어 시 자동 |
| SEL | 챕터2 `MQ-2-1` 클리어 시 자동 |
| LIR | 챕터3 `MQ-3-4` 클리어 시 자동 |
| **NAI** | 챕터4 `MQ-4-3`에서 **살려두는 선택**을 했을 때만. 처치 시 영구 미영입 |

네이르만 조건부인 이유 — 5명 전원 자동 합류면 "동료를 모은다"가 절차가 됩니다. 한 명은 놓칠 수 있어야 하고, 그 한 명이 이교도 시선을 가진 인물이어야 [엔딩 '범람'](02-카르마-명성-시스템.md#72-엔딩-매트릭스) 노선의 무게가 생깁니다.

## 3. ID 체계 및 데이터 구조

### 3.1 퀘스트 ID

```
MQ-{챕터}-{순번}        메인          예) MQ-3-4
SQ-{지역코드}-{순번}     서브          예) SQ-SAV-07
CQ-{동료코드}-{단계}     동료 개인      예) CQ-SEL-2
DQ-{던전코드}-{순번}     던전 내        예) DQ-D01-3
```

### 3.2 지역 코드

| 코드 | 지역 | 챕터 | 코드 | 지역 | 챕터 |
|---|---|:---:|---|---|:---:|
| `STV` | 시작의 마을 | — / 1 | `NOB` | 부패 귀족령 | 3 |
| `FRS` | 시작의 숲 | 튜토리얼 | `CLF` | 고요한 절벽의 성채 | 4 |
| `SAV` | 사바나 마법 대도시 | 1 | `RUI` | 무너진 마나 도시 | 4 |
| `ZNC` | 제노스 신정국 수도 | 2 | `FOR` | 변성 숲 | 4 |
| `MIN` | 폐광 | 2 | `IRN` | 철과 기계의 도시 | 5 |
| `OCN` | 해양 대도시 | 3 | `NEX` | 대륙 마나 결절지 | 5 |

던전 코드: `D00` 폐광 던전 · `D01` 리테르나 · `D02` 아스트리움 타워 · `D03` 심연의 성가 · `DFN` 진화로

### 3.3 퀘스트 데이터 스키마

```
Quest
  quest_id        PK      varchar     -- 위 ID 체계
  title           varchar
  type            enum    -- main, sub, companion, dungeon
  category        enum    -- 토벌 / 수집 / 조사 / 호위 / 배달 / 선택 / 제작
  chapter         int
  region_id       FK
  level_min       int                 -- 권장 레벨 하한
  prereq_quests   int[]               -- 선행 퀘스트
  prereq_flags    varchar[]           -- 선행 플래그
  prereq_standing json                -- 세력 평판 조건 (02 §5.4)
  exp_reward      int                 -- 06 §5.3 예산에서 산출
  gold_reward     int
  item_rewards    json
  d_renown        int                 -- 02 §3.2
  d_karma         int
  d_standing      int[5]
  set_flags       varchar[]           -- 완료 시 세우는 플래그
  branch_group    varchar             -- 배타 분기 그룹 (같은 그룹은 하나만 수행 가능)
```

### 3.4 플래그 · 변수 규약

```

FLAG_CHOICE_{이름}     bool    되돌릴 수 없는 선택
VAR_{이름}             int     누적/카운터
```

## 8. 엔딩 분기 스크립트

[02 §7.2](02-카르마-명성-시스템.md#72-엔딩-매트릭스)의 매트릭스를 실행 가능한 조건식으로 확정합니다. **위에서부터 순서대로 평가하고, 처음 일치하는 엔딩을 채택합니다.**

```
IF 파티 동료 수 == 0
    → 홀로 남은 용사

ELSE IF VAR_ENDING_CHOICE == 3 (계승)
     AND 카르마 >= 60
     AND 전 동료 Bond >= 60
     AND FLAG_CHOICE_D01_THIRD
     AND FLAG_D02_CERES_TRUTH
    → 진 엔딩 : 또 하나의 이야기

ELSE IF VAR_ENDING_CHOICE == 3 AND 카르마 < -60
    → 참칭자

ELSE IF VAR_ENDING_CHOICE == 3 AND FLAG_D02_CERES_TRUTH
    → 성좌의 계승자

ELSE IF VAR_ENDING_CHOICE == 2 (개방) AND 최다평판 == SIL
    → 범람

ELSE IF VAR_ENDING_CHOICE == 2 AND 최다평판 == SER AND 카르마 >= 0
    → 새로운 균형

ELSE IF VAR_ENDING_CHOICE == 1 (봉인) AND 카르마 < -30
    → 정화의 대가

ELSE IF VAR_ENDING_CHOICE == 1
    → 회귀

ELSE
    → 회귀 (기본값)
```

### 8.1 진 엔딩 조건 검토

조건 5개 동시 충족입니다. 1회차 자연 달성률 추정:

| 조건 | 단독 달성률 (추정) |
|---|---:|
| 계승 선택 | 33% |
| 카르마 ≥ +60 | 25% |
| 전 동료 Bond ≥ 60 | 20% |
| `FLAG_CHOICE_D01_THIRD` (숨겨진 데이터 결합) | 15% |
| `FLAG_D02_CERES_TRUTH` (로그 3종 회수) | 40% |

단순 곱은 0.1%로 지나치게 낮지만, **네 조건이 서로 상관관계가 높습니다** — 숨은 요소를 찾는 플레이어는 대체로 동료 퀘스트도 하고 카르마도 관리합니다. [02 K-07](02-카르마-명성-시스템.md#11-미해결-이슈)의 목표(1회차 3~5%)에 맞추려면 조건을 4개로 줄여야 할 수 있습니다.

**조정안 (베타 판정)** — `카르마 ≥ +60` 을 `카르마 ≥ +30` 으로 완화. 진 엔딩이 "완벽한 선인"의 보상이 아니라 "끝까지 파고든 사람"의 보상이 되도록.

### 8.2 에필로그

```
본편 엔딩 재생
  ↓
동료별 에필로그   Bond >= 80 인 동료마다 1편  (최대 5편)
  ↓
세력별 후일담     평판 >= +40 인 세력마다 1편 (최대 5편)
  ↓
크레딧
```

세력별 후일담이 [04 사업성 §3.2](04-사업성-손익-계획.md#32-확장팩-dlc--원본-p209-가격-측정-필요의-답)의 DLC(확장팩 후일담)와 연결되는 지점입니다.
